# Komentář k zákonu č. 503/2012 Sb., o Státním pozemkovém úřadu a o změně některých souvisejících zákonů

Otevřený komentář k zákonu o Státním pozemkovém úřadu — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; organizace úřadu, rezerva státních pozemků, hospodaření a propachtování, bezúplatné a úplatné převody zemědělských pozemků, veřejná nabídka a veřejná soutěž, kupní cena, přechod z Pozemkového fondu a změny souvisejících zákonů.

Konsolidované znění: dokument e-Sbírky `SB-2012-00503_2026-01-01`.
